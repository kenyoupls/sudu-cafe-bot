Cafe Manager Bot

A Telegram bot that runs your cafe — cleaning, stock, shifts, events, content, and more.

Free to host & run

How It Works

Feature Modules

🧹Cleaning

Scheduled cleaning rounds with zone buttons. Staff tap to confirm. Tracks what's done and what's left.

/clean/cleanstatus
📦Stock & Inventory

Interactive stock check across 8 categories. OK / LOW / OUT buttons. Auto-adds low items to shopping list.

/stock/stockcheck/lowstock
✅Checklists

Interactive opening (10 items) and closing (11 items) checklists with tap-to-mark and completion tracking.

/open/close
👥Staff & Shifts

Staff registry, weekly shift schedule, and auto-reminders 30 minutes before each shift starts.

/shifts/addshift/staff
🕐Operating Hours

Set regular hours by day. Override with holiday/school-break hours on specific dates.

/hours/sethours/holiday
📅Events

Plan upcoming events with dates and details. Auto-reminders for today's and tomorrow's events.

/events/addevent
🛒Shopping List

Shared buy list with urgency flags. Low-stock items auto-added. Mark items as bought.

/buy/addbuy/bought
📱Content Ideas

Daily content nudge from a pool of 15 ideas. Tracks what's been posted to avoid repeats.

/content/contentlog
💬Natural Language

Staff can type naturally — "cleaned toilets", "running low on milk" — and the bot routes it to the right action.

just type
📊Reports

Daily dashboard and weekly overview. Shows checklist status, cleaning, stock, shifts, events at a glance.

/today/week

Quick Start

Get a bot token

Message @BotFather on Telegram → /newbot → copy the token

Add bot to your cafe group

Add it as a member, then send /setup to get the Group Chat ID

Set environment variables

TELEGRAM_BOT_TOKEN, GROUP_CHAT_ID, CAFE_NAME, TIMEZONE

Deploy to free host

Push to GitHub → connect to Koyeb or Oracle Cloud → bot goes live

Register staff and shifts

/addstaff Sarah barista → /addshift mon Sarah 8:00-16:00

3 files · ~900 lines of Python · Zero monthly cost
